# Team conventions

1. Read AGENTS.md before working; it points to every contract document.
2. Respect file ownership (AGENTS.md, Team structure). Do not modify another member's module without coordinating with its owner.
3. Consult the relevant skill in `.agents/skills/` for specialised tasks; see SKILL_USAGE.md.
4. Do not silently alter shared interfaces. Changes to API_CONTRACT.md, DATABASE_SCHEMA.md or UI_GUIDELINES.md need Tech Lead approval and an announcement before dependent members continue.
5. Follow ARCHITECTURE.md. Ask the Tech Lead before changing architecture.
6. No unapproved dependencies. Propose additions before installing.
7. Explain significant implementation decisions in the PR description.
